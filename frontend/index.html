How it works

A cabinet run that fits the wall, the budget and the look, with every part number checked.

  1. 01

    Read the photo

    OpenCV evens out lighting and finds the floor line, the wall corner and the camera tilt.

  2. 02

    Match the style

    CLIP embeddings search Qdrant for modules that look like the room and your brief.

  3. 03

    Enforce physics

    SQL filters width, depth, clearance and stock, then a solver fills the run within budget.

  4. 04

    Write the spec

    An LLM writes the install notes from verified rows only. Any unverifiable output is rejected.
